# wp-plugin-boilerplate

Khung plugin chuẩn (core/ + features/) để nhân bản khi làm plugin mới.

## Cài / dùng

Tải file zip trong **Releases** → WordPress → Plugin → Cài mới → Tải plugin lên → Kích hoạt.
